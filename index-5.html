ABSTRACT

This project presents the design and implementation of an Automatic Conveyor Filling System using the Omron CP2E PLC, programmed in ladder logic via CX-Programmer. The system automates the transport, detection, filling, and discharge of containers on a conveyor production line. A proximity sensor detects container arrival at the filling station, halts the conveyor, and activates the fill valve for a preset duration. A second sensor at the exit confirms successful dispatch. An ON-Delay Timer (TON) fault-detection mechanism monitors for jams or blockages and triggers an alarm, halting the process to prevent equipment damage. The project demonstrates sensor integration, timer-based control, sequential automation, fault detection, and PLC ladder logic — key skills for industrial automation engineers.

SECTION 01
System Overview & Components
The system uses an SMPS-fed Omron CP2E as the central controller, interfacing START/STOP pushbuttons, two proximity sensors, a conveyor motor, a filling valve, and an alarm buzzer. The SMPS provides regulated 24 V DC to all control-level devices, ensuring noise immunity.
SECTION 02
Operational Sequence
START → Conveyor runs → Sensor-1 detects container → Conveyor stops → Fill Timer T0 activates valve (5 s) → Valve closes → Conveyor restarts → Sensor-2 confirms exit → Cycle repeats. Pressing STOP at any time deactivates motor, valve, and alarm.
SECTION 03
Fault / Jam Detection
Jam Timer T1 (8 s preset) monitors exit detection after conveyor starts. If Sensor-2 does not trigger within T1, the Fault Bit (W0.01) is set, the alarm output (100.02) energises, and the system halts. The fault latches until the operator presses START to reset.
SECTION 04
Ladder Logic Structure (6 Rungs)
Rung 0: START/latch. Rung 2: Conveyor motor control (interlock with fill state). Rung 17: SET W0.01 on Sensor-1 detection. Rung 9: Fill Timer T0 start. Rung 13: Fill valve activation on T0 complete. Rungs 20–23: Completion timer T1 → RSET W0.01 to resume cycle.
SECTION 05
Industrial Applications
Food & beverage bottling lines · Pharmaceutical vial filling · Chemical drum dispensing · Paint & lubricant canning · Consumer goods packaging · Agricultural seed/fertiliser bag filling.
SECTION 06
Future Enhancements
HMI integration for real-time monitoring · Analog fill-level sensors for precise quantity control · SCADA connectivity for remote supervision · Multi-station independent control zones using additional CP2E units · Variable-speed conveyor via VFD.

CONCLUSION

This project demonstrates the implementation of an Automatic Conveyor Filling System using the Omron CP2E PLC with ladder logic in CX-Programmer. The system realises START/STOP control with latching, proximity-sensor-driven conveyor and filling actions, and a timer-based fill mechanism. Jam and fault detection are incorporated with alarm annunciation. The project highlights core industrial automation principles including sealed latch logic, TON timer usage, output interlock design, and fault-safe system architecture. The modular rung layout makes the program straightforward to maintain and debug, and the design is scalable for real industrial deployment.
